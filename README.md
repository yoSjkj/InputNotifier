**입력장치 알리미 기획안**

**목적**
멀티 스위칭 키보드와 마우스가 지금 폰에 붙어 있는지 상태표시줄 아이콘으로 바로 알 수 있게 한다.

**동작**
- 앱 화면에서 페어링된 블루투스 기기 목록을 보고, 기기마다 종류(키보드 / 마우스 / 기타)를 지정한다
- 지정된 기기가 연결되면 종류별 아이콘이 상태표시줄에 뜨고, 끊기면 사라진다
- 기타 종류는 공용 아이콘을 쓰고, 알림창에서 기기 이름으로 구분한다

**구현 방식**
- 매니페스트에 등록한 리시버로 `ACTION_ACL_CONNECTED/DISCONNECTED`를 받는다. 상주 서비스 없음
- 이벤트가 오면 지정된 기기인지 확인하고 해당 알림을 띄우거나 지운다
- 기기를 처음 지정할 때는 현재 연결 상태를 직접 확인해서 바로 반영한다
- 알림 중요도 LOW (소리·진동 없이 아이콘만)

**아이콘**
- Google Material Symbols 사용 (Apache 2.0)
- 상태표시줄: `keyboard`, `mouse`, `devices_other`
- fonts.google.com/icons에서 Android XML로 받아 `res/drawable`에 넣는다
- 런처 아이콘: 같은 세트로 구성, 세부 디자인은 개발하면서 결정

**권한**
- `BLUETOOTH_CONNECT`
- `POST_NOTIFICATIONS`

**사용 조건**
- 앱을 강제 종료하면 다시 열 때까지 동작하지 않음
- 갤럭시 배터리 설정에서 절전 예외로 등록 권장

**기술스택**
- Kotlin, XML 뷰
- SharedPreferences (기기 MAC 주소, 종류 저장)
- 개발 환경: 폰 Android Code Studio + Termux

**진행 단계**
1. 기기 목록과 종류 지정 화면
2. 리시버와 알림 표시
3. 하루 써보면서 절전 끊김 여부 확인, 필요하면 "짧게 끊겼다 다시 붙으면 무시" 옵션 추가
